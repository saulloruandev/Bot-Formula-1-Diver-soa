# Imagens de eventos da corrida

Adicione imagens PNG nesta pasta com estes nomes (todas são opcionais):

- `ultrapassagem.png`
- `colisao.png`
- `rodada.png`
- `pneu.png`
- `quebra_motor.png`
- `safety_car.png`
- `bandeira_vermelha.png`
- `volta_rapida.png`

O bot só publica uma imagem quando o arquivo correspondente existe. Sem imagens locais, os eventos continuam aparecendo normalmente no painel e no histórico da corrida.
