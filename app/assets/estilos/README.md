# Imagens dos estilos de pilotos

O arquivo `links.json` associa o nome exato de cada estilo a uma URL direta de imagem (`https://...`). Preencha o valor correspondente para exibir a foto do piloto no perfil. Use links diretos para imagens PNG, JPG ou WEBP, preferencialmente de fontes com permissão de uso. Se o campo ficar vazio, o perfil usa a foto personalizada do jogador, se houver.
